# Алиса: актуальная схема

Сценарии Яндекса для отдельных фраз больше не являются целевой схемой и настраивать их не нужно.

Используется один приватный диалоговый навык. Владелец один раз говорит: «Алиса, запусти навык Домашний дворецкий», после чего свободно разговаривает с локальной моделью Home Butler в рамках одной сессии. Команды Home Assistant входят в тот же разговор.

Актуальная инструкция: [ALICE-FULL-DIALOG-SETUP.md](ALICE-FULL-DIALOG-SETUP.md).

Старый `alice_voice_bridge.py` с четырьмя фиксированными маршрутами выключен и
удалён из автозапуска. Его unit оставлен только как ручной аварийный откат;
новые сценарии для него создавать не нужно.
